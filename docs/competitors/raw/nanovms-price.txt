
NanoVMs utilizes an on-demand pricing model, billed per second with a one-minute minimum. They also indicate that most cloud providers offer an always-on VM running a unikernel for approximately $4/month. The smallest instance or memory size is not explicitly defined as a fixed unit, but their documentation states that memory is "Only Limited by Instance Size" and can reach up to 1400GB. They claim that even their smallest instance types are more cost-effective than Lambda or Cloud Run offerings. For cold-start or boot-time, an un-optimized Nanos workload demonstrated a boot time of around 60ms.
