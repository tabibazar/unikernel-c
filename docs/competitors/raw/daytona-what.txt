Its offerings include process execution, file system operations, Git integration, and LSP support. The service is optimized for AI applications such as AI evaluations, code interpreters, coding agents, data analysis, data visualization, and reinforcement learning. Daytona runs workloads on microVMs, which offer full OS-level isolation, a shift from its earlier use of shared-kernel containers.
