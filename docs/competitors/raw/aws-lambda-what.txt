
AWS Lambda MicroVMs, powered by Firecracker virtualization, offer isolated, stateful code execution within a serverless compute primitive. These MicroVMs launch nearly instantly, preserve full memory and disk state for up to 8 hours, and automatically suspend when idle. They provide VM-level isolation, running each tenant on an isolated kernel, memory space, and disk state. The isolation technology used is Firecracker microVMs.
