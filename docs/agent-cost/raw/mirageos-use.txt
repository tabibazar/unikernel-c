
MirageOS is a "library operating system" designed for building secure, high-performance network applications as unikernels. These unikernels are efficient, have a minimal attack surface, and are suitable for deployment in cloud environments and on embedded devices.

Documented production or industrial users of MirageOS include:

*   **Docker Desktop**: It uses VPNKit, which leverages MirageOS to bridge the compatibility between Linux primitives and macOS or Windows, handling network traffic for numerous containers.
*   **Tarides**: This company utilizes MirageOS for its Mr. MIME project, a library built on unikernels for secure email traffic handling.
*   **Mirage.io Website**: The official MirageOS website runs as a self-hosted MirageOS appliance on the Xen hypervisor.
*   **http://decks.openmirage.org**: This platform uses distinct MirageOS appliances for presenting conference slides.
