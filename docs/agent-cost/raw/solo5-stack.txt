
Solo5 does not provide a specific network stack or libc. It functions as a sandboxed execution environment that redefines the interface between a unikernel application and its host. Unikernels running on Solo5 are therefore expected to provide their own network stack and libc implementation, which then interact with the host through Solo5's minimal API.
