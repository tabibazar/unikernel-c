
The Unikernel-Linux project supports TLS through its own re-engineered implementation called "nqsb-TLS". This custom TLS stack is designed to address security vulnerabilities found in existing TLS implementations. The "nqsb-TLS" can be compiled into Xen unikernels and is used to support applications such as HTTPS, IMAP, Git, and Websocket clients and servers.
