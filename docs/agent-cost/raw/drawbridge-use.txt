
The Microsoft Research project 'Drawbridge' was a research prototype focused on a new form of virtualization for application sandboxing. It combined a 'picoprocess' (a lightweight isolation container) with a 'library OS' (a version of Windows adapted to run within the picoprocess). The goal was to provide secure isolation, persistent compatibility, and execution continuity with reduced resource overhead compared to traditional virtual machines. While Drawbridge could run various Windows applications as a prototype, it was explicitly stated as a research project and not a production system. There are no documented production or industrial users of Drawbridge; the project has concluded, and its influence is primarily seen in its contribution to concepts for secure containers, for example, potentially in SQL Server on Linux.
