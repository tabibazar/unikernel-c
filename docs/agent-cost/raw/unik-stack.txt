
For unikernels built using UniK with the Rumprun project, the network stack used is the TCP/IP stack provided by rump kernels. This is a portable, kernel-quality driver component. Regarding the libc, Rumprun is designed to support existing unmodified POSIX software, and the rump kernel architecture provides the system calls needed for a standard libc to operate effectively, allowing a standard POSIX-compliant libc to be used.
