
IncludeOS is a library operating system (a type of unikernel) designed for single-task computers. It allows applications to be compiled with the necessary operating system functionality directly into the application itself, resulting in a standalone, bootable image. This approach aims to solve several problems: improved security through immutability and a reduced attack surface, smaller image and memory footprint, and enhanced performance and predictable low latency due to the absence of context switches. A key application area for IncludeOS is Virtual Networking Appliances, such as firewalls and load balancers, where the developers have observed excellent performance compared to Linux. However, based on the pages I have read, there are no documented production or industrial users of IncludeOS.
