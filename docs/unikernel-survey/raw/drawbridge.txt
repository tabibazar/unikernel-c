
Microsoft Research's Drawbridge project is a research prototype of a new form of virtualization for application sandboxing. The implementation language is C/C++, as it is a modified version of Windows and utilizes Windows 8 binaries. The project is archived, as explicitly stated on its official Microsoft Research page. Drawbridge targets a custom "picoprocess" isolation container rather than traditional hardware hypervisors.
